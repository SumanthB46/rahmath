# Mubarak — Luxury Surfaces & Ceramics

A cinematic architectural showcase for luxury tiles, Italian marble, granite slabs, and bespoke integrated sinks.

## Tech Stack
- **Framework**: TanStack Start (SSR) + Vite + Nitro
- **Language**: TypeScript + React
- **Styling**: Tailwind CSS
- **Motion & Smooth Scroll**: GSAP + Lenis

## Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build
```
